## 슬라이드 구분자 — `---`

* 빈 줄 사이의 `---` 단독 줄이 슬라이드를 나눔

```markdown
## 첫 슬라이드
* 내용

---

## 다음 슬라이드
* 내용
```

* frontmatter 종료 `---`과 본문 분리 `---`을 혼동하지 않도록 주의

---

## 헤더 컨벤션

| 레벨 | 역할 | 비고 |
| :--- | :--- | :--- |
| `H1` | 챕터 그룹 | Markmap에서 그룹 노드 |
| `H2` | 슬라이드 제목 | 각 슬라이드의 메인 타이틀 |
| `H3` | 슬라이드 내 하위 섹션 | 권장 사용 |

* 슬라이드 마크다운은 **H1 다수가 정상** (일반 문서 단일 H1 규칙 면제)

---

## Frontmatter 필수 필드

* 파일 첫 줄부터 `---`로 감싸 작성

```yaml
---
title: 슬라이드 제목
type: ppt           # 필수 — 슬라이드 모드로 처리
subtitle: 부제      # 선택
author: 발표자      # 선택
date: 2026-06-30    # 선택
---
```

* `type: ppt`가 있어야 H1마다 슬라이드로 분리됨

---

## AGENDA.md 형식

* 챕터를 **인라인 링크**로 연결 (형식 필수)

```markdown
## [01. m2slide란?](./01-what-is-m2slide.md)
## [02. 빠른 시작](./02-quickstart.md)
### [2.1 하위 챕터](./02.1-sub.md)
```

* `H2` = 메인 챕터(별도 HTML) · `H3` = 하위 챕터
* 제목과 링크를 분리한 형식(`## 제목` + 별도 링크 줄)은 인식되지 않음

---

## 리스트 · 표 · 코드 블록

* 1단계 불릿은 `*`, 2단계 이하는 `-`
    - 중첩 항목 예시
* 표는 작게 (4~5열 이하)

```python
def hello():
    return "code block — 언어 지정 필수"
```

* 코드 블록은 항상 언어를 지정해 구문 강조를 받음

---

## 단계별 등장 (Fragment)

* 즉시 표시되는 항목
* `{.fragment}`로 한 단계씩 등장 {.fragment}
* `{.fragment .fade-up}` 방향 효과도 가능 {.fragment .fade-up}
* reveal.js `<!-- .element: -->` 주석도 동등 지원 {.fragment .highlight-blue}

> 이 슬라이드 자체가 fragment 동작 예시 — `→` 키로 항목이 순서대로 나타남
