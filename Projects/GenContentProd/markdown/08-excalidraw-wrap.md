# 08. Excalidraw + Part1 정리

## Excalidraw 개요 — 손그림 + AI 보조



* Excalidraw: 손그림 느낌의 자유 다이어그램 도구
* 진입점:
  * excalidraw.com (웹·무료)
  * VSCode Excalidraw 확장 (오프라인·.excalidraw 파일)
* 특징:
  * 손그림 톤 — 정형 도구보다 친근·발산적
  * Text-to-Diagram: 텍스트 입력 → AI가 자동 다이어그램 생성
  * 라이브러리 — 자주 쓰는 도형 묶음 재사용
* 비교: 정형·자동 → Mermaid / 자유·창의 → Excalidraw

## Mermaid vs Excalidraw — 언제 무엇을



* Mermaid 선택:
  * 정형 다이어그램 (flowchart·sequence·class·gantt)
  * 텍스트 코드 기반 → Git 버전관리·AI 생성 친화
  * 일관된 톤·자동 레이아웃
* Excalidraw 선택:
  * 발산·브레인스토밍·아이디어 스케치
  * 손그림 톤이 어울리는 자료 (워크숍·교육)
  * Text-to-Diagram으로 1차 초안 후 자유 편집
* 본 강의 권장: 정식 문서는 Mermaid, 워크숍·발표 보조는 Excalidraw

## 🙋 Excalidraw 실습 — 손그림 1장 + Text-to-Diagram 1장

* 작업: 동일 주제를 두 방식으로 그리기 — “Prompt-to-Publish 5단계”
* 절차:
  * Step 1: excalidraw.com 접속
  * Step 2: (손그림) 박스 5개 + 화살표로 5단계 표현 — 3분
  * Step 3: (Text-to-Diagram) AI 메뉴 → “Prompt-to-Publish 5단계 flowchart” 입력
  * Step 4: 자동 생성된 다이어그램 확인 → 자유 편집
  * Step 5: PNG·SVG 저장
* 시간: 7분
