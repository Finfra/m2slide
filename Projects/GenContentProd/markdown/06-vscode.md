# 04. VSCode 기본기

## VsCode란?

* Microsoft에서 개발한 무료 개발자 도구
* 경량 코드 편집기로서 Windows·macOS·Linux 크로스 플랫폼 지원

![VsCode란?](img/GenContetntsProd_v10_10.png)

---

## 주요 기능

* **코드 편집**: 자동 완성·구문 강조·들여쓰기, 플러그인으로 다양한 언어·프레임워크 지원
* **디버깅**: 중단점 설정·변수 값 확인으로 버그 추적·수정
* **Git 통합**: 변경 내역 추적·버전 관리·비교·병합을 편집기 안에서 수행
* **플러그인 생태계**: 색 테마·스니펫·언어 지원 등 확장으로 개발 환경 커스터마이징
* **통합 터미널**: 내장 터미널에서 명령 실행 → 편집기와 함께 개발 효율화

## 편집 기능 - 여러줄 선택

* 단축키: `Ctrl + Alt + (↑, ↓)`
* 1단계: Ctrl + Alt 키를 누른 상태에서 위·아래 방향 화살표로 세로 선택 영역 조절
* 2단계: 세로로 여러 줄 선택 후, `Shift + (←, →)`로 가로 영역 선택 가능
* 3단계: 세로 영역 선택 상태에서 텍스트 수정 → 선택된 모든 줄에 동시 반영

## 추천 기능

* 자동 완성 기능
  * vsCode는 코드 작성 시 자동 완성 기능을 제공
  * 변수, 함수, 클래스 등의 이름을 입력하는 도중에 자동으로 후보 목록을 제시하여 작성 속도를 향상시킴.
* 구문 강조 기능
  * vsCode는 다양한 프로그래밍 언어에 대한 구문 강조 기능을 제공.
  * 코드의 구조와 요소를 색상으로 강조하여 가독성을 높여줌.
* 들여쓰기 기능
  * vsCode는 코드 작성 시 자동으로 올바른 들여쓰기를 적용하여 가독성을 향상시킴.
  * 개발자는 들여쓰기에 신경 쓰지 않고 코드 작성에 집중 가능.

---

## 추천 기능 (계속)

* Git 통합
  * vsCode는 내장된 Git 통합 기능을 제공합니다. 코드 변경 내역을 추적하고 버전 관리 가능.
  * 변경 내역을 비교하고 병합하는 등의 작업을 간편하게 수행 가능.
* 통합 터미널
  * vsCode는 내장된 터미널을 제공하여 개발 작업을 원할하게 수행함.
  * 터미널에서 명령어를 실행하고 프로젝트 관리 가능.
  * 터미널과 코드 편집기를 함께 사용하여 개발 작업을 효율적으로 진행 가능.
* 기능이 안 보이면: `Ctrl+Shift+A` (명령 팔레트)

## 플러그인 설치

* 활동바(왼쪽 사이드바) 확장 아이콘 클릭 → 확장명 검색 → Install
* 검색창에 안나오면: `Ctrl+Shift+A` (확장 검색 팔레트 직접 열기)
* 수천 개 이상의 무료 확장 제공 — 필요한 언어·도구 지원 즉시 추가 가능

---

## 필수 단축키 5개

* `Cmd/Ctrl+P`: 파일 빠르게 열기 — 파일명 일부만 입력
* `Cmd/Ctrl+Shift+P`: 명령 팔레트 — VSCode 모든 기능 검색
* `Cmd/Ctrl+B`: 사이드바 토글 — 작업 공간 넓히기
* `` Cmd/Ctrl+` ``: 터미널 토글 — 명령 실행
* `Cmd/Ctrl+Shift+V`: Markdown 미리보기 분할
* 외우는 팁: P(파일) · Shift+P(명령) · B(바) · `(터미널) · Shift+V(뷰)

---

## 필수 확장 4종

* **Markdown All in One**: 자동 목차·표 정렬·키맵 강화
* **Mermaid Preview**: Markdown 안의 mermaid 코드블록 즉시 렌더링
* **Excalidraw**: VSCode 안에서 손그림 작성·저장
* **GitLens**: 줄별 누가 언제 바꿨는지 표시 — 협업·버전관리 친화
* 설치 방법: 활동바 확장 아이콘 → 확장명 검색 → Install
* 4종 모두 무료 — 본 강의 진행에 충분
