# 01. 강의 시작·오프닝

## 강의 시작 — 인사·강사 소개



* 강사 남중구 (핀프라)
  * 보조강사 : 환경 구성 오류 1차 응답·실습 도우미 역할
* Q&A는 각 섹션 끝·쉬는 시간에 분산 운영
* 본 강의 자료는 계속 업데이트되는 다이나믹 자료 입니다
  * 현재 기준 : Claude Model Sonnet 4.6 or Opus 4.7

## 강의 목표

* **목표 1**: 프롬프트 엔지니어링 6대 패턴 — LLM 출력 품질을 제어
