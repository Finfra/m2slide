# 02. Diffusion·인포그래픽·시각 자산

## Diffusion 이미지 생성 도구 비교

* **ChatGPT (DALL·E 3)**: 일반 사용성 최상, ChatGPT Plus 통합 — 무료 한도 제한
* **Gemini Imagen**: 한글 텍스트 렌더링 양호, Google 계정 친화
* **Bing Image Creator**: 무료 사용 가능, DALL·E 기반
* **Midjourney**: 아트워크 품질 최상, Discord 진입 장벽 있음·유료
* **본 강의 권장**: ChatGPT(품질·접근성) + Gemini(한글 텍스트) 2종 병행
* **선택 기준**: 한글 텍스트 필요 여부 / 무료 한도 / 아트워크 톤

## 이미지 프롬프트 4요소



* 주체(Subject): 무엇을 그릴 것인가 — 명사 중심으로 명확히
  * ex) “젊은 한국인 여성 바리스타”
* 스타일(Style): 어떤 화풍·매체 — 회화/사진/일러스트/3D
  * ex) “수채화 풍, 종이 질감”
* 구도(Composition): 카메라 시점·배치 — 클로즈업/전신/조감도/대칭
  * ex) “측면 클로즈업, 중앙 배치”
* 라이팅(Lighting): 빛 방향·시간·분위기 — 자연광/역광/네온/황혼
  * ex) “창문 측면 자연광, 따뜻한 톤”
* 4요소를 한 문장으로 결합 → 일관된 결과


---

## Diffusion 모델 개요

* **동작 원리(간단히)**: 노이즈 이미지 → 단계적으로 노이즈 제거 → 의미 있는 이미지
* **사용자 입장**: 텍스트 프롬프트 → 수십 초 → 완성 이미지
* **대표 모델 계열**: Stable Diffusion / DALL·E / Imagen / Midjourney
* **이미지 1장 생성 비용**: 무료~$0.04 수준 (도구별 차이)
* **본 강의 포커스**: 원리보다 “프롬프트→결과” 사이클 반복

## 🙋 강의 표지 1장 생성 실습 — 직접 따라 하세요



* 작업: 본 강의의 “표지 이미지” 1장 생성
* 프롬프트 템플릿:
  * 주체: “1일차 강의 표지 — Prompt-to-Publish 워크플로우”
  * 스타일: “미니멀 일러스트, 파스텔 톤”
  * 구도: “중앙 정렬, 텍스트 영역 상단 여백”
  * 라이팅: “부드러운 자연광”
* 절차:
  * Step 1: ChatGPT 또는 Gemini에 4요소 결합한 1문장 입력
  * Step 2: 1차 결과 확인 → 마음에 안 들면 1요소만 수정 후 재생성
  * Step 3: 최종 1장 저장 → 본인 노트북 바탕화면에 임시 저장

## AI 시각 자산 5종 비교

* **5종**: Diffusion(사진·일러스트) / 인포그래픽(Napkin·Gamma) / SVG(Claude Design) / 다이어그램(Mermaid) / 손그림(Excalidraw)
* **비교 4축**: 자유도 / 일관성 / 수정 용이성 / 텍스트 정확도
* **빠른 선택 가이드**:
  - 표지·삽화 → Diffusion
  - 수치·플로우 시각화 → 인포그래픽
  - 정밀 SVG·재사용 → Claude Design
  - 정형 다이어그램(코드 기반) → Mermaid
  - 발산·브레인스토밍 → Excalidraw
* 본 강의는 5종 모두 1회 이상 직접 사용

## 인포그래픽 4대 패턴 — 유형별 요약

* **통계**: 수치를 시각적으로 강조 — 막대·원·게이지·하이라이트
  - ex) “사용자의 87%가…”
* **플로우**: 단계·절차·의사결정 흐름 — 화살표·박스
  - ex) “신청 → 검토 → 승인 3단계”
* **비교**: 2~N개 항목의 축별 차이 — 표·매트릭스·레이더 차트
  - ex) “A vs B vs C 4축 비교”
* **타임라인**: 시간 순서·이정표 — 가로/세로 선 + 노드
  - ex) “2020→2024 5단계 마일스톤”

## 인포그래픽 도구 선택 가이드

* **Napkin AI**: 텍스트 입력 → 자동 인포그래픽 추천. 무료·웹 기반·초보 친화
* **Gamma**: 슬라이드 + 인포그래픽 통합. 발표 자료 한 번에 — 무료/유료
* **ChatGPT + Claude Design**: 정밀 SVG 1장씩 — 디자이너 친화
* 빠른 선택:
  - 5분 안에 1장 → Napkin AI
  - 발표 자료 통째로 → Gamma
  - 강의·문서에 박을 정밀 SVG → Claude Design
* 무료 한도 차이 있음 — 작업 빈도에 맞춰 1개를 주력으로 선정 권장

## 1페이지 인포그래픽 프롬프트 작성법



* 좋은 인포그래픽 프롬프트의 5요소:
  * 주제 1문장 (무엇에 대한 인포그래픽인가)
  * 표현 패턴 (통계/플로우/비교/타임라인 중 1)
  * 핵심 데이터 3~5개 (수치·라벨)
  * 톤·색감 (전문·캐주얼·다크·라이트)
  * 출력 비율 (1:1·4:3·9:16)
* 예시: “AI 도구 5종 비교 인포그래픽, 비교 패턴, 도구명·평점 5쌍, 다크 톤, 16:9”
* 결과가 흐릿하면: 데이터 개수 줄이기 + 패턴 1개로 단순화

## 🙋 Napkin AI 실습 — 직접 따라 하세요



* 작업: “AI 도구 5종 비교” 1페이지 인포그래픽 생성
* 절차:
  * Step 1: napkin.ai 접속 (Google 계정 로그인)
  * Step 2: 텍스트 입력란에 도구명·1줄 설명 5쌍 입력
  * Step 3: “Generate” → 자동 추천 인포그래픽 3~5종 확인
  * Step 4: 마음에 드는 1종 선택 → 색감·아이콘 수정
  * Step 5: PNG 또는 SVG로 다운로드
* 시간: 7분
* 평가: 데이터 5개가 모두 시각적으로 구분되는지
* 💡 강사 메모: Napkin은 “텍스트→자동 추천” 흐름이 핵심. 청중이 추천 안 중에서 고르는 감각 익히게 함.


---

## 🙋 Gamma 실습 — 직접 따라 하세요



* 작업: “이번 주 회의 요약” 1슬라이드 인포그래픽 생성
* 절차:
  * Step 1: gamma.app 접속 (Google 계정 로그인)
  * Step 2: “Generate” → 텍스트 입력란에 회의 안건·결정사항 5줄
  * Step 3: 자동 생성된 슬라이드 1장 선택
  * Step 4: 톤·레이아웃 수정 (자유 편집)
  * Step 5: PDF로 export
* 시간: 7분
* 평가: 1슬라이드 안에 안건·결정사항이 한눈에 보이는지

## 산출물 비교·정리



* 본 단원에서 만든 인포그래픽 2장(Napkin + Gamma)을 옆 사람과 교환
* 비교 체크리스트:
  * 데이터 5개가 모두 보이는가
  * 색감이 메시지와 맞는가
  * 1눈에 메시지가 파악되는가
* “내가 자주 만드는 보고서·발표 자료”에 둘 중 어떤 도구가 맞을지 1줄 메모
* 도구 선택은 작업 빈도 + 협업 환경(공유·편집 가능 여부)에 좌우됨
