# ..show / ..ask 실시간 데모

::: htmlart compare
* **..show** / 단방향 렌더
  - 결과를 문서로 보여줌
  - 앞 챕터에서 확인
* **..ask** / 양방향 Q&A
  - 선택지를 폼으로 물어봄
  - 답을 자동 회수
:::

* 공통점: 프롬프트에 트리거 한 단어만 붙이면 브라우저가 알아서 뜨고, 사람은 화면에서만 상호작용함
* 채팅에 긴 선택지를 늘어놓고 번호로 답하던 흐름을 **클릭 가능한 폼**으로 바꿈

---

# ..ask — 폼으로 묻고 자동 회수

```mermaid
graph LR
  A[AskUserQuestion] --> B[HTML 폼 생성]
  B --> C[사용자 선택·전송]
  C --> D[서버 inbox]
  D --> E[Claude 자동 수신]
```

* 선택지를 채팅에 늘어놓는 대신 **체크박스·자유 입력 폼**으로 제시함
* 사용자가 전송하면 Claude가 `Poll form answer inbox`로 응답을 자동 회수해 작업을 이어감
* 브라우저가 없을 땐 채팅에 항목명·번호를 직접 입력하는 fallback도 지원함

---

# 실제 폼 화면

::: columns
:::: {.column width="42%"}
* "제거할만한 폴더 제안해줘. ..ask" 입력 → 브라우저에 뜬 **복수 선택 폼**
* 각 항목에 근거(용량·수정일·권장 여부)가 함께 표시되어 판단이 쉬움
* `전송` / `전송 후 닫기` / `전송 후 해당 세션으로` 버튼으로 응답과 흐름을 동시에 제어
* 우측 Claude 패널은 `Poll form answer inbox`로 폴링 중

> "질문 → 답변 대기 → 수신"이 한 흐름으로 이어져 맥락이 끊기지 않음
