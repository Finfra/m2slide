## 마크다운 한 벌이면 끝

::: htmlart process
* ✍️ 마크다운
  - .md 한 벌 작성
* ⚙️ m2slide.sh
  - 명령 한 줄
* 🎁 4종 산출물
  - HTML · EPUB
  - PDF · PPTX
:::

---

## 한 번 쓰고, 네 가지로 낸다

| 산출물 | 옵션     | 용도                     |
| :----- | :------- | :----------------------- |
| HTML   | (기본)   | Reveal.js 브라우저 발표  |
| EPUB   | `--epub` | 전자책                   |
| PDF    | `--pdf`  | 배포·인쇄                |
| PPTX   | `--pptx` | PowerPoint 호환          |

* `.md` 하나가 모든 형식의 원본(SSOT)
