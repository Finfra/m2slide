## 도구와 씨름 끝, 콘텐츠에 집중

::: htmlart compare
* **기존 방식** / 도구가 주인공
  - 슬라이드·전자책·PDF 도구 따로따로
  - 바이너리 포맷 — diff·리뷰 불가
  - 디자인 맞추다 시간 소진
* **m2Slide** / 콘텐츠가 주인공
  - 마크다운 하나로 전부 생성
  - Git으로 버전 관리·협업
  - theme 한 줄로 디자인 교체
:::

---

## 네 가지 이유

::: htmlart radial
* m2Slide
* 단일 SSOT
  - .md 하나가 원본
* Git 친화
  - diff·리뷰·협업
* 확장 자유
  - theme·layout·컴포넌트
* 즉시 시작
  - 마크다운만 알면 끝
:::

---

## 발표가 편해진다

* **Markmap 목차** — 클릭 가능한 마인드맵 자동 생성
* **계층 네비게이션** — 챕터 간 이동 자동 연결
* **단계별 등장** — `{.fragment}` 한 토큰이면 끝
* **차트·수식·mermaid·3D** — 펜스드 블록으로 바로 삽입
