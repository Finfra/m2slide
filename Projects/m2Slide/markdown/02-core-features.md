* 마크다운 한 벌 → 4종 산출물 + 인터랙티브 목차

---

## 4종 출력 형식

| 형식 | 옵션     | 용도                                   |
| :--- | :------- | :------------------------------------- |
| HTML | (기본)   | Reveal.js 프레젠테이션 (브라우저 발표) |
| EPUB | `--epub` | 전자책 (iBooks·Calibre·Google Play)    |
| PDF  | `--pdf`  | 챕터별 합본 PDF (decktape)             |
| PPTX | `--pptx` | PowerPoint 호환 (pandoc)               |

* 하나의 `.md`가 모든 형식의 원본(SSOT)

---

## 발표를 돕는 요소

* **Markmap 목차**: 클릭 가능한 인터랙티브 마인드맵 자동 생성
* **계층 네비게이션**: 챕터·하위 챕터 자동 연결, 상위 페이지 버튼
* **단계별 등장**: `{.fragment}`로 항목 순차 표시
* **자동 layout**: 이미지만 있는 슬라이드는 자동 풀스크린
