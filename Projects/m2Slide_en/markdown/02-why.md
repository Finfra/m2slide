## Stop Fighting Tools, Focus on Content

::: htmlart compare
* **The old way** / Tools take center stage
  - Separate tools for slides, e-books, PDFs
  - Binary formats — no diff, no review
  - Time drained matching designs
* **m2Slide** / Content takes center stage
  - Everything from one Markdown source
  - Version control and collaborate with Git
  - Swap the design with one theme line
:::

---

## Four Reasons

::: htmlart radial
* m2Slide
* Single SSOT
  - One .md is the source
* Git-friendly
  - diff · review · collaborate
* Freely extensible
  - theme · layout · components
* Start instantly
  - Just know Markdown
:::

---

## Presenting Gets Easier

* **Markmap TOC** — auto-generated clickable mind map
* **Hierarchical navigation** — automatic links between chapters
* **Step-by-step reveal** — one `{.fragment}` token does it
* **Charts · math · mermaid · 3D** — drop in via fenced blocks
