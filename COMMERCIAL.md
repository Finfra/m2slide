# Commercial Licensing for m2slide

Most people never need this page. m2slide's source code is Apache-2.0, and its bundled
themes are free to use as long as the generated presentations keep the attribution line
"Powered by finfra.kr, Made by m2slide" on their first and last slides.

## When you need a commercial license

| Situation                                                                            | Why                 |
| :----------------------------------------------------------------------------------- | :------------------ |
| Generated output **without** the "Powered by finfra.kr" attribution (bundled themes) | theme/LICENSE.md §3 |
| Using the m2slide name or logo on your own product or service                        | TRADEMARK.md        |

Presentations built with a theme **you authored yourself** (one that does not include or
derive from the files under theme/) are never subject to these terms.

## What you get

* A perpetual license for attribution-free output, covering all versions released

* Priority handling of bug reports.
